# Homebrew tap for Harfi

[Harfi](https://github.com/Mustafa-Abbara/arabizi-keyboard) turns Lebanese Arabizi into Arabic as you type, entirely on your Mac.

```bash
brew install --cask mustafa-abbara/harfi/harfi
```

Then turn it on once: System Settings → Keyboard → Input Sources → Edit… → + → Arabic → Harfi. The install guide is [docs/INSTALL.md](https://github.com/Mustafa-Abbara/arabizi-keyboard/blob/main/docs/INSTALL.md).

`Casks/harfi.rb` is copied from each release (`harfi.rb` asset).
