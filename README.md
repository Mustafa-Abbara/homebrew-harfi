# Homebrew tap for Harfi (archived)

This tap is no longer used. Homebrew quarantines what it downloads, and macOS blocks a quarantined app that is not signed with a paid Apple Developer ID, so Harfi cannot be installed this way for now.

Install Harfi with one line instead, as [docs/INSTALL.md](https://github.com/Mustafa-Abbara/arabizi-keyboard/blob/main/docs/INSTALL.md) explains:

```bash
curl -fsSL https://raw.githubusercontent.com/Mustafa-Abbara/arabizi-keyboard/main/scripts/install_harfi.sh | bash
```
